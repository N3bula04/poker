# Chipless

A single-page browser poker chip tracker. **This is a personal learning project**, not a commercial product.

**Live:** [https://n3bula04.github.io/poker/](https://n3bula04.github.io/poker/)

Set players and stacks, then track antes, bets and pots as you play. Everything stays in your browser (`localStorage`). No accounts and no API keys.

## Run it locally

Clone this repository (or download `index.html` and `pot.js` into the same folder) and open `index.html` in a browser. Or serve the folder with `python3 -m http.server 8080` and visit [http://127.0.0.1:8080/](http://127.0.0.1:8080/).
